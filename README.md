**Можно ли поставить поиск на паузу?**
Да, в один клик — в боте или в кабинете. Пауза не удаляет поиск: возобновить можно в любой момент; лимит тарифа действует на активные поиски — поставив поиск на паузу, вы освобождаете слот.
